# SuperHero WebAPI

## Overview
SuperHero WebAPI is a simple **ASP.NET Core Web API** application that allows users to manage superhero data. It provides CRUD operations for creating, updating, retrieving, and deleting superhero records.

## Technologies Used
- **ASP.NET Core Web API**
- **C#**
- **Entity Framework Core**
- **SQL Server**

## Features
- CRUD operations for superheroes
- API endpoints for managing superhero data

## API Endpoints

| Resource    | Endpoint             | Method  |
|-------------|----------------------|---------|
| Superheroes | `/api/superheroes`    | GET     |
| Superheroes | `/api/superheroes/{id}` | GET     |
| Superheroes | `/api/superheroes`    | POST    |
| Superheroes | `/api/superheroes/{id}` | PUT     |
| Superheroes | `/api/superheroes/{id}` | DELETE  |

## Setup

### Prerequisites
- **.NET SDK 8.0+**
- **SQL Server**
